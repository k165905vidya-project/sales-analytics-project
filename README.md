# Sales Analytics Project

## Project Overview
This project focuses on cleaning, analyzing, and interpreting sales data to identify business trends and provide actionable business insights.

The objective is to demonstrate practical data analytics skills using Microsoft Excel.

## Project Objectives
- Clean and prepare raw sales data.
- Handle missing values and inconsistent categories.
- Calculate important sales KPIs.
- Analyze sales performance by product, region, and month.
- Identify business trends and opportunities.
- Provide actionable business recommendations.

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- KPI Reporting
- Data Visualization
- Business Insights

## Key Performance Indicators (KPIs)
- Total Operating Sales: $9,838,141.37
- Average Order Value: $32,469.11
- Total Operating Orders: 303
- Total Units Ordered: 97,029
- Number of Customers: 92

## Key Findings
- Classic Cars was the highest-performing product line.
- EMEA generated the highest regional sales.
- North America was the second-highest-performing region.
- The analysis identified 60 cancelled transaction line items.
- Monthly sales trends were reviewed to understand performance over time.

## Business Recommendations
1. Focus marketing efforts on high-performing product lines.
2. Develop targeted strategies to improve sales in lower-performing regions.
3. Monitor cancelled orders to identify reasons for lost sales.
4. Use monthly sales trends to improve inventory and sales planning.
5. Strengthen customer retention through targeted offers and engagement.
